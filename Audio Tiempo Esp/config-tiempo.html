Configurar secuencias

Para guardar secuencias en el repo, escribe tu llave de GitHub (se queda solo en este celular).

Cómo crear tu llave:
  1. En la compu entra a github.com → tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token, ponle nombre (ej. app-tiempo).
  3. En Repository access elige Only select repositories y marca Juego-Actividades.
  4. En Permissions → Contents elige Read and write.
  5. Generate token, cópiala y pégala aquí.

Elige una carpeta para ver o crear su secuencia (.json).
